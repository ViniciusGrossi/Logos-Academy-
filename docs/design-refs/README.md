## Diretrizes para as três explorações

- Preservar Academy Orange, ink/gray, Inter e JetBrains Mono.
- Usar Explorer Purple, Builder Orange e Engineer Blue/Green apenas como sinalização semântica.
- Público principal: jovens de 12–17 anos; evitar tanto infantilização quanto estética corporativa fria.
- A tela inicial do aluno é orientada à próxima ação, não a métricas.
- O admin precisa de densidade operacional legível e hierarquia calma.
- A marca deve aparecer com respiro, sem placa branca, glow exagerado ou logo ampliada como decoração.
- Motion funcional, discreto e compatível com `prefers-reduced-motion`.
